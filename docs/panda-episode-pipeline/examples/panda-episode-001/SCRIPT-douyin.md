# 熊猫 Episode #001 — 凌晨 3 点,熊猫为什么不睡

> **Voice**: 御宅 + 治愈
> **Pattern**: 深夜独处 · 反问自己 · 不说教
> **Platform**: 抖音 (主) + B站 + 小红书
> **Duration**: 58 秒
> **Status**: 选题已 AI 候选,脚本待配音/画面

## 这是什么?

OPC panda IP 的第一期内容,基于 `/api/ai/topics` (seed="深夜3点,刚下播,看着窗外")
返回的 6 个候选里人工挑选的"凌晨 3 点,熊猫为什么不睡"。

为什么选这个:
- **双 voice 命中** (御宅 + 治愈),后续可以拆条做 A/B
- **时间锚点强** ("凌晨 3 点" 是抖音深夜流量的命门)
- **反问结构** ("为什么不睡" 而不是 "教你不 emo"),避开说教陷阱
- **情绪投而不收** (留白结尾,不喊"愿你被温柔以待"的口号)

## 关键情绪锚点

| 时间 | 情绪 | 镜头语言 |
| --- | --- | --- |
| 0-3s | 钩子: 反问 | 黑屏白字 (打破流) |
| 3-14s | 铺垫: 设定场景 | 远景 → 侧脸,慢推 |
| 14-20s | 转折: 30 万人 vs 没人问 | 中景,表情凝重 |
| 20-28s | 留白: 没答 | 抬头看窗外,慢推 |
| 28-36s | 反差: 评论区 vs 不点赞 | 手机特写 |
| 36-48s | 出口: 站起来 | 拉镜到窗外全景 |
| 48-55s | 共鸣: 够了 | 黑屏白字 |
| 55-58s | 收尾: 出品 | 背影 + 字幕 |

## 避坑清单 (这是上一期复盘下来的)

- ❌ **不说 "加油" / "愿你被温柔以待"** — 抖音上 5 秒就划走
- ❌ **不喊 "家人们"** — 这是 2024 年的梗,2026 年 30+ 用户已经疲惫
- ❌ **不堆 BGM 情绪拉满** — 钢琴 + 雨声白噪足矣,情绪靠留白
- ❌ **不显 IP 露出** — 熊猫穿日常家居服,不戴品牌 logo

## 验收标准 (3 天后看数据)

- [ ] **首 3 秒完播率** > 65% (反问钩子的命门)
- [ ] **整体完播率** > 22% (深夜慢节奏内容均值)
- [ ] **点赞率** > 4% (这是 panda IP 阈值)
- [ ] **评论** > 50 条 (深夜情绪内容有共情裂变)
- [ ] **收藏** > 点赞 (情绪类内容应被收藏而非仅点赞)

如果 3 天数据:
- 全部达标 → 出 "凌晨 3 点系列" 第 2 期 (选题见 episodes.md)
- 完播 < 18% → 改 hook (3 秒内的反问 → 改成 1 个画面钩子)
- 点赞 < 3% → 改结尾 (留白 → 共鸣)
