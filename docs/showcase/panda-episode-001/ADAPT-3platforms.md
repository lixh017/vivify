## B站版 — 「凌晨 3 点,没人问我为什么不睡」

> 2:40,长视频深聊,把反问变成开放讨论

### 结构

```
[0:00-0:15]  开场钩子
   镜头: 跟抖音版一样的窗边,但更慢,留 3 秒纯雨声
   旁白: "这是凌晨 3 点的我。但我今天想讲的不是我,
   是我那只熊猫。"

[0:15-0:45]  故事铺垫
   镜头: 切到真实录屏 (手机屏幕, 抖音后台数据)
   旁白: "今天发了 1 条视频,30 万人看了。但那 30 万人
   里,有没有 1 个,是真的'看见'他?"

[0:45-1:30]  深度发问
   镜头: 切回窗边,正面中景,慢推到特写
   旁白: "凌晨 3 点,我的熊猫没睡,没点赞,没回评论。
   他可能在想:
     - 是不是我给的不够?
     - 是不是我笑得太僵?
     - 还是,我自己其实也不确定,这件事到底该不该被做?"

[1:30-2:00]  真实回答
   镜头: 切到书桌, 摊开的手稿 (剧本文本可见,真实)
   旁白: "做了 3 个月,30 万是常态,但凌晨 3 点的那个
   沉默,才是常态。我没答案。但我想把这个'没答案'
   留给系列。"

[2:00-2:30]  互动钩子
   镜头: 窗边全景
   旁白: "如果你也在凌晨 3 点,你也'不睡'。评论区
   留一句你凌晨在想的事。我会读每一条。"

[2:30-2:40]  出字幕收尾
   字幕: "熊猫 OPC · 凌晨 3 点系列 / 001"
   关注引导
```

**B站版关键差异**:
- 节奏更慢,留白更多,B站用户耐心 2:40
- 把"反问"做成"开放讨论",评论区是重点
- 真实后台数据 + 手稿露出来 = "真诚感"(B站用户最吃这个)
- 没有结尾"留白",B站需要明确的"系列预告"

**预计发布窗口**:B站用户活跃 22:00-01:00,选周五 23:00

## 小红书版 — 「凌晨 3 点的我,在干嘛」

> 45s,情绪速写,图强于文,求助式

### 结构

```
[0:00-0:03]  封面卡 (静态图,4 屏轮播)

  封面 1: 窗边背影,大字 "凌晨 3 点,你也这样吗?"
  封面 2: 茶 + 手机特写, 字 "30 万人看过我,没人问过我"
  封面 3: 评论区截图 (脱敏), 字 "今天没点赞,任何一条"
  封面 4: 站起来背影, 字 "—— 熊猫 OPC 凌晨 3 点系列"

[0:03-0:20]  慢节奏视频 (跟抖音版相同的窗边镜头)
   旁白: 删到只剩 4 句
     "凌晨 3 点,我在窗边。"
     "今天有 30 万人看了我。"
     "但没人问我,为什么还不睡。"
     "我也没答。"

[0:20-0:35]  加速: 4 张静态图快切 (跟封面同)
   文字快闪: "30 万 / 1 个 / 凌晨 3 点 / 1 个问题"
   背景音: 心跳 + 雨声

[0:35-0:43]  回到窗边全景, 慢拉
   旁白 (字幕,不是配音): "你也在吗? 评论 1 个字
   告诉我。"

[0:43-0:45]  收尾, 出 tag
   字幕: "凌晨 3 点系列 / 001 · 关注熊猫 OPC"
```

**小红书版关键差异**:
- 静态封面比视频更吸量 (4 屏轮播,首屏决定 CTR)
- 旁白砍到 4 句,图 + 字为主
- 求助式结尾 ("评论 1 个字") 是小红书裂变核心
- 5-10 个相关 tag 是必须的 (#治愈 #深夜emo #熊猫 #独处 #3点 #失眠 #IP #创作)

**预计发布窗口**:小红书用户 21:00-23:00 流量大,选周六 22:00

## 节奏对比 (3 平台同一个钩子的不同处理)

| 钩子元素 | 抖音 | B站 | 小红书 |
| --- | --- | --- | --- |
| "凌晨 3 点" 时间锚点 | 0-3s 黑屏文字 | 0-15s 留白慢推 | 0-3s 封面大字 |
| 30 万人 vs 没人问 | 14-20s 中景 | 0:45-1:30 慢推 | 20-35s 文字快闪 |
| 不点赞的反差 | 28-36s 手机特写 | (无,改成"没答案") | (无,改成求助) |
| 共鸣结尾 | 48-55s 黑屏白字 | 2:00-2:30 评论引导 | 0:35-0:45 评论 1 个字 |
| 留白 vs 互动 | 留白 (命门:完播) | 互动 (B站要深度) | 互动 (小红书要裂变) |

**3 个版本不复制粘贴的核心**:
- 抖音:留白 → 完播率
- B站:深度 → 关注 + 收藏
- 小红书:求助 → 评论数

每个平台的"完成动作"不同,所以钩子和收尾的设计也必须不同。
