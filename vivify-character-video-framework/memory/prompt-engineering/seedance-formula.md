# Seedance 2.0 — 7-element prompt formula

> Source: official 火山方舟 (Ark) Seedance 2.0 prompt-engineering guide.
> Status: ✅ validated — used in all fengge EP003–EP006 prompts.

## The 公式

每个 shot prompt **必须** 包含 7 个元素, 顺序固定:

```text
精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件
```

| # | 元素 | 作用 | 例子 |
|---|---|---|---|
| 1 | 精准主体 | WHO — 不能模糊 (别说 "a man", 说 "中年男性, 山羊胡, 灰色长衫") | 峰哥, 成年熊猫, 朱红汉服, 半阖眼, 手持折扇 |
| 2 | 动作细节 | WHAT — 具体的身体动作, 不要抽象情绪 | 右手缓缓展开折扇, 左手轻抚杯沿 |
| 3 | 场景环境 | WHERE — 背景 + 道具 + 时代感 | 竹林小院, 青石板, 雨后青苔, 远处炊烟 |
| 4 | 光影色调 | HOW IT LOOKS — 光的方向 + 色温 + 饱和度 | 晨光斜照, 暖橙 + 翠绿, 低饱和 |
| 5 | 镜头运镜 | CAMERA — 1 个运镜, 不能多 | 缓慢推进, 焦点在脸部, 背景轻微虚化 |
| 6 | 视觉风格 | STYLE — 媒介 / 画风 / 笔触 | 2D 国潮 gouache, 笔触明显, 印章红色块 |
| 7 | 画质 | QUALITY — 4K / 高细节 / 抗锯齿 | 高细节, 锐利边缘, 无后期滤镜 |
| 8 | 约束条件 | NEVER — 反向防止跑偏 | 保持无字幕, 不要生成水印, 不要生成 Logo, 不要生成边框 |

## 分镜结构 (multi-shot)

当一个 prompt 包含 ≥ 2 个 shot, **必须** 用分镜标记:

```text
镜头 1: [运镜] [主体] [动作] [位置] [音频]
镜头 2: [运镜] [主体] [动作] [位置] [音频]
镜头 3: [运镜] [主体] [动作] [位置] [音频]
```

**音频列在每个镜头内部**, 跨镜头的 BGM 在 prompt 最末尾统一写.

Example (EP004 治愈调 3-shot 开场):

```text
镜头 1: 静止中景 峰哥 (朱红汉服) 坐在竹林小院的青石板上, 右手搭在膝盖, 左手轻抚茶杯边沿, 雨后青苔泛着微光, 晨光斜照, 国潮 gouache 笔触, 4K 高细节, 保持无字幕 不要生成水印 不要生成 Logo
音乐(古琴泛音 + 雨声) 音效<水滴落在青苔> 台词{"嗯……今天的雨,有点意思。"} 字幕【】

镜头 2: 缓慢推进 峰哥 (朱红汉服) 站立, 转身面向远山, 折扇半展, 风轻吹动衣摆, 背景虚化, 国潮 gouache, 4K, 保持无字幕 不要生成水印
音乐(古琴持续) 音效<折扇展开> 无台词

镜头 3: 静止近景 (特写脸部) 峰哥 半阖眼 微微笑意, 眼睛不直视镜头, 看下方茶杯, 暖光打亮半边脸, 国潮 gouache, 4K, 保持无字幕 不要生成水印
音乐(古琴淡出) 音效<远处犬吠> 台词{"嘿……要不,你也来一口？"} 字幕【】
```

## Special character syntax

| 语法 | 含义 | Example |
|---|---|---|
| `音乐(...)` | BGM, 跨镜头持续 | `音乐(古琴泛音)` |
| `音效<...>` | 单次音效, 在该镜头发生 | `音效<折扇展开>` |
| `台词{...}` | 角色对白, 自动 lip-sync | `台词{"嘿……"}` |
| `字幕【...】` | 屏幕字幕, **默认空** | `字幕【】` (我们永远不放字幕, 让 ffmpeg 后压) |

> ⚠️ **字幕永远空** — 字幕由 ffmpeg 后期压, 不让 Seedance 生成, 否则字体会失控.

## Camera movement rules (strict)

- **1 个 shot = 1 个运镜**. 写多了 Seedance 会"折中", 每个运镜都只做 50%.
- 运镜词必须从官方清单里选, 不要自己造:

| 类别 | 词 |
|---|---|
| 静止 | 静止 / 固定机位 |
| 推进/拉远 | 缓慢推进 / 快速推进 / 缓慢拉远 / 快速拉远 |
| 摇 | 左摇 / 右摇 / 上摇 / 下摇 |
| 移 | 左移 / 右移 / 上移 / 下移 |
| 跟 | 跟拍 / 跟随 |
| 升降 | 升起 / 下降 / 俯冲 |
| 特殊 | 航拍 / 环绕 / 推拉变焦 (dolly zoom) / 一镜到底 |

- ❌ WRONG: "镜头 1: 推进 + 摇 + 拉远 + 环绕" — 4 个运镜模型全打折
- ✅ RIGHT: "镜头 1: 缓慢推进" — 1 个运镜做满

## Emotion-to-action mapping (抽象 → 具象)

**绝对不要**在 prompt 里写抽象情绪词 (沉思, 喜悦, 紧张). 必须用具象身体动作.

完整 mapping 见 [`emotion-actions.md`](./emotion-actions.md).

| 抽象情绪 | ❌ 不要写 | ✅ 应该写 |
|---|---|---|
| 沉思 | "峰哥沉思" | "峰哥 低头, 眼睛望下方, 手指轻抚杯沿, 呼吸变慢" |
| 喜悦 | "峰哥 喜悦" | "峰哥 嘴角上扬, 眉眼舒展, 脚步变轻" |
| 紧张 | "峰哥 紧张" | "峰哥 频繁看窗外, 手指不停敲桌, 肩膀微微僵硬" |
| 释然 | "峰哥 释然" | "峰哥 长长舒一口气, 肩膀放松, 微微仰头" |

## Always-on constraints (在每个 shot 末尾都加)

```text
保持无字幕, 不要生成水印, 不要生成 Logo, 不要生成边框
```

原因:
- Seedance 在中文 prompt 里偶尔会自己加字幕 (特别是有 `台词{...}` 时)
- Logo / 水印 / 边框 出现率虽然 < 5%, 但不加就会出现
- "保持无字幕" 必须在 `台词` 之后, 否则模型搞不清哪个是约束

## What's WRONG with our old prompts (EP001–EP002)

对比 旧 vs 新:

| 旧 (EP001) | 新 (EP003+) |
|---|---|
| 1 段连续文字, 没分镜 | `镜头 1: ... 镜头 2: ...` |
| "峰哥很沉思地看着远方" | "峰哥 低头, 眼睛望下方, 手指轻抚杯沿" |
| "镜头缓慢推进然后右摇再拉远" | "镜头 1: 缓慢推进" |
| 没有 NEVER clause | 末尾 4 条约束 |
| 没说画质 | 4K 高细节 锐利边缘 |
| 没说风格 | 2D 国潮 gouache |
| `字幕{"嘿……"}` 试图让模型生成字幕 | `字幕【】` + ffmpeg 后压 |

EP001 翻车率: ~40%. EP003+ 翻车率: < 5%.
