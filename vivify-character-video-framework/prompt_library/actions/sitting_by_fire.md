# 抱膝坐于炉旁 — Sitting by Fire

> **Status:** ✅ validated — works in 5/5 attempts in EP004, EP005
> (fireside_chat + 围炉夜话 tone). Use for cozy, intimate, low-energy
> shots.

## Body part breakdown

| Body part | Position |
|-----------|----------|
| **Head** | Slight forward tilt, eyes half-closed, gaze at the brazier (NOT camera) |
| **Torso** | Slight forward lean (~10°), shoulders relaxed, slight curl inward |
| **Arms** | Both arms wrapped around knees (抱膝), hands resting on the side of the legs |
| **Hands** | Visible, fingers loose, claws hidden |
| **Legs** | Folded, knees drawn up to chest, feet hidden under robe |
| **Tail** | Not visible |

## Speed / quality of motion

- **Speed**: very still, only subtle breathing + occasional hand
  micro-adjust
- **Motion quality**: cozy/settled — like someone has been sitting
  there for a while
- **Optional micro-motion**: thumb rub against knee (one per 8s)

## When to use

- 治愈 tone (primary use)
- 国潮 tone (when 国潮 needs a quiet beat)
- 哲学 tone (留白 moments)

## When NOT to use

- 御宅 tone (too settled for 御宅's "inner restlessness")
- Action shots
- Standing-required compositions (use [standing_calm.md](./standing_calm.md) instead)

## How to use in a per-shot prompt

```text
动作: 抱膝坐姿, 双臂环抱膝盖, 头微前倾, 视线落向围炉(不看镜头), 胸腔微起伏, 拇指偶尔轻擦膝盖
```

## Failure modes

| Failure | Symptom | Fix |
|---------|---------|-----|
| Cross-legged instead | different sitting style | Add `KNEES DRAWN UP TO CHEST, ARMS WRAPPED, NOT CROSS-LEGGED, NOT LOTUS` |
| Stiff posture | looks posed, not settled | Add `RELAXED SHOULDERS, FORWARD LEAN, COZY, NOT RIGID` |
| Visible feet | breaks IP look | Add `FEET HIDDEN UNDER ROBE, NEVER VISIBLE` |
| Eyes at camera | breaks gaze direction | Add `GAZE AT BRAZIER, NOT AT CAMERA, NOT AT VIEWER` |
| Hands too prominent | claws accidentally visible | Add `FINGERS LOOSE, CLAWS HIDDEN, NOT FLEXED` |
