# 倚窗望雨 — Leaning on Window, Watching Rain

> **Status:** ✅ validated — works in 5/5 attempts in EP003, EP005.
> Use for 哲学 / 治愈 tones when the scene calls for solitude, a
> 留白 moment, and 1-2 props (window + optional rain).

## Body part breakdown

| Body part | Position |
|-----------|----------|
| **Head** | Tilted slightly, resting on the window frame, eyes looking out (NOT camera) |
| **Torso** | Side-leaning against the window frame, ~20° tilt |
| **Right arm** | Either resting on the window sill, or holding a 茶盏 |
| **Left arm** | At side or behind back |
| **Hands** | Loose, optional cup-hold, claws hidden |
| **Legs** | Standing, slight bend in one knee (the leaning leg) |
| **Tail** | Not visible |

## Speed / quality of motion

- **Speed**: very still, only subtle breathing + occasional blink
- **Motion quality**: contemplative, settled, has-been-here-a-while
- **Optional micro-motion**: slow blink every 5s, thumb rub on
  window sill

## When to use

- 哲学 tone (primary)
- 治愈 tone (when a quiet indoor beat is needed)
- 御宅 tone (with the right indoor cozy register)

## When NOT to use

- 国潮 tone (too settled/quiet — use [holding_fan.md](./holding_fan.md) or [walking_slow.md](./walking_slow.md))
- Outdoor scenes (use [walking_slow.md](./walking_slow.md) or [standing_calm.md](./standing_calm.md))
- Action shots

## How to use in a per-shot prompt

```text
动作: 侧倚窗框, 头微靠窗棂, 视线向窗外(不看镜头), 单手扶窗台(可选持茶盏), 单膝微屈, 静(无明显动作, 仅呼吸)
```

## Failure modes

| Failure | Symptom | Fix |
|---------|---------|-----|
| Direct window stare at camera | breaks gaze direction | Add `GAZE OUT WINDOW, NOT AT CAMERA, NOT AT VIEWER, OFF-FRAME` |
| Stiff leaning | looks posed | Add `RELAXED LEAN, WEIGHT ON WINDOW FRAME, NOT RIGID, NOT UNCOMFORTABLE` |
| Both arms on sill | looks like waiting for bus | Add `ONE ARM ON SILL OR HOLDING CUP, OTHER AT SIDE, NOT BOTH ON SILL` |
| Visible feet | breaks IP look | Add `FEET HIDDEN UNDER ROBE, NEVER VISIBLE` |
| Lying down on sill | breaks pose | Add `LEANING AGAINST FRAME, STANDING/SLIGHT BEND, NOT LYING, NOT ON SILL` |
